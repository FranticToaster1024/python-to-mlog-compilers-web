# python-to-mlog-compilers-web
An **unofficial** web playground for various python to mlog ([Mindustry](https://github.com/anuken/mindustry/) Logic) compilers.


# Requirements
Included compilers must:
- be implemented in python (since this project uses pyodide)
- have a license that allows such use
